# Telegram-конектор: Telethon, синхронізація, підготовка до демо — 2026-11-24

Для Telegram-конектора вибрали Telethon, бо Bot API не бачить особисті чати. Курсор синхронізації зберігається окремо для кожного чату й оновлюється в одній транзакції зі вставкою повідомлень. Для самарі використовуємо Claude з JSON-форматом. Додано захист від подвійних запусків через lock у SQLite, тести на краш посеред синхронізації проходять без пропусків. Демо заплановано на п'ятницю, відео записує Ольга.

## Рішення
- Використовувати Telethon для Telegram-конектора, бо Bot API не бачить особисті чати
- Курсор синхронізації зберігати окремо для кожного чату й оновлювати в одній транзакції з вставкою повідомлень
- Для самарі використовувати Claude, формат JSON: підсумок, рішення, задачі, відкриті питання
- Періодичну синхронізацію запускати раз на 30 хвилин
- Логи демо-прогонів класти в docs/demo
- Відредаговані повідомлення поки не підтягувати, це піде в обмеження
- Захист від подвійних запусків реалізовано через lock у SQLite
